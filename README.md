# johll

A family portal, in Phase 0. `CLAUDE.md` is the build contract.

The page published from this repo is a prototype. Every time, place and event in it is invented. People appear as the codes H, K, A1 and A2 until someone signs in on that device with the family code, which unlocks the names held in an encrypted file. The code is not in this repo.

* Run it locally: `npm run serve`, then open http://localhost:8080
* Run the tests: `npm test`

Fonts (Bricolage Grotesque, Hanken Grotesk, Geist Mono) are under the SIL Open Font Licence. Icons are Phosphor, MIT licence.
